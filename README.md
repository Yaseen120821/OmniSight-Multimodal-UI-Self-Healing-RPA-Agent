> **OmniSight** is an enterprise-grade autonomous testing and Robotic Process Automation (RPA) platform designed to detect, analyze, and repair web UI defects in real time using browser automation, computer vision, and multimodal AI vision models.

---

## 📖 Executive Summary

Traditional UI automation frameworks frequently fail due to fragile DOM selectors, changing element IDs, dynamic CSS class renames, and subtle visual layout shifts. **OmniSight** solves this brittleness by pairing **Playwright browser automation** with **OpenCV / SSIM computer vision** and **multimodal AI vision models**. When a selector breaks or a layout shifts, OmniSight autonomously identifies the target element visually, heals the selector in real time, and logs diagnostic evidence for QA and engineering teams.

## ✨ Key Features & Architecture

### 🛡️ Enterprise Light SaaS Admin Dashboard
- **Minimal Enterprise Aesthetic**: Designed with clean white cards (`#ffffff`), soft slate backgrounds (`#f8fafc`), dark slate typography (`#0f172a`), and vibrant primary blue accents (`#2563eb`).
- **Responsive Layout**: Adapts gracefully across desktop (`1440px`), tablet (`768px`), mobile (`390px`), and small mobile (`320px`) viewports with a collapsible slide-over navigation drawer.

### 📊 Business Analytics & KPI Overview
- **6 Real-Time Metric Cards**: Tracks **Total Projects (14)**, **Test Executions (248)**, **Passed Tests (219)**, **Failed Tests (29)**, **Overall Pass Rate (88.3%)**, and **Self-Healing Success Rate (93.3%)**.
- **Interactive 7-Day Execution Trend**: Visual stacked bar chart illustrating daily passed, failed, and self-healed test executions with hover tooltips and screen reader accessible data tables.
- **Defect Category Distribution**: Breakdown of identified defects into *Visual Shift*, *Selector Change*, *Timeout Error*, and *Assertion Failure*.

### ⚡ Target Application Inventory & Dual Pagination
- **Dual Pagination Controls**: Positioned **above** and **below** the target table for rapid navigation.
- **Dynamic Filtering & Reset**: Real-time project search by name, target URL, or project ID combined with status filters (*All*, *Passed*, *Failed*, *Repaired*, *Running*). Automatically resets pagination to Page 1 on filter modification.
- **Target Registration**: Modal interface for registering new target web applications into the active monitoring schedule.

### 💾 Centralized Persistence Store (`lib/store.ts`)
- **Real-Time LocalStorage Sync**: Automatically syncs target registrations, test execution logs, and activities across browser sessions without data loss or duplicate counting upon page refresh.
- **Dynamic Metric Computations**: All statistics are dynamically derived from underlying test execution objects.

### 📄 Detailed Test Run Reports (`/reports/[id]`)
- **Assertion-by-Assertion Granularity**: Complete breakdown of DOM selectors, assertion types (*visual*, *functional*, *element_exist*, *text_match*), pass/fail status, and failure stack traces.
- **Autonomous Self-Healing Log**: Records broken selectors, replacement locators generated by Vision AI, confidence scores, and validation statuses.
- **Visual Regression Comparison**: Side-by-side display of **Baseline Screenshot**, **Actual Execution**, and **Visual Diff Overlay**.
- **Executive & Technical Diagnostics**: Tailored summary reports for product stakeholders and software developers.

### 📥 Multi-Page PDF & CSV Export Engine
- **One-Click PDF Generation**: Integrates `jspdf` and `html2canvas` to render multi-page executive report PDFs containing metric cards, assertion tables, visual diffs, and developer diagnostics.
- **CSV Data Export**: Download raw assertion data and execution history in standard CSV format.

## 🚀 Getting Started

### Prerequisites

- **Node.js**: `v18.17.0` or higher (`v20+` / `v24` recommended)
- **npm**: `v9+` or higher

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Yaseen120821/OmniSight-Multimodal-UI-Self-Healing-RPA-Agent.git
   cd OmniSight-Multimodal-UI-Self-Healing-RPA-Agent/frontend
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open **[http://localhost:3000](http://localhost:3000)** in your browser.

4. **Run production build verification**:
   ```bash
   npm run build
   ```

5. **Run ESLint static code analysis**:
   ```bash
   npm run lint
   ```

## 🧪 Automated Testing & Playwright Locator Registry

OmniSight is built for automated testability. Key interactive components include stable `data-testid` attributes:

| Element Description | `data-testid` Attribute | Usage |
| :--- | :--- | :--- |
| **Analytics Metrics Grid** | `dashboard-metrics` | Locate the 6 analytics KPI cards |
| **Projects Table Container** | `projects-table` | Locate target application records table |
| **Target Search Input** | `project-search` | Search target projects by name or URL |
| **Status Filter Controls** | `project-status-filter` | Filter targets by *All*, *Passed*, *Failed*, *Repaired*, *Running* |
| **Run Test Button** | `run-test-button` | Trigger mock test suite execution |
| **Sidebar Navigation** | `sidebar-nav` | Locate main navigation drawer links |
| **Mobile Menu Toggle** | `mobile-menu-button` | Toggle navigation drawer on mobile viewports |
| **Notifications Toggle** | `notification-button` | Open accessible notification panel |
